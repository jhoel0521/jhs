jhs

Oculta la pantalla y bloquea teclado y mouse sin cerrar nada, y programa el apagado. Para Windows y Linux, desde la terminal o desde tu agente de IA.

Descargar Código en GitHub

Modo privacidad

Tus servidores, pruebas y descargas siguen corriendo mientras nadie puede ver ni tocar el PC.

Apagado programado

En N minutos o a una hora exacta, con avisos y cancelación en un comando.

Hecho para IA

Salida --json, códigos de salida estables y una skill versionada para Claude Code.

Ligero y sin admin

Un agente en tu sesión, en Rust. Se instala sin administrador ni sudo y se actualiza solo con jhs update.

Instalación

tar -xzf jhs-*-linux-x86_64.tar.gz
./jhs-*/jhs install
Expand-Archive jhs-*-windows-x86_64.zip .
.\jhs-*\jhs.exe install
git clone https://github.com/jhoel0521/jhs && cd jhs
cargo build --release
./target/release/jhs install

Skill para agentes de IA (Claude Code y otros), con npx skills:

npx skills add jhoel0521/jhs --skill jhs -g -a claude-code -y
npx skills update jhs -g -y

Uso

jhs --off-screen            # modo privacidad
jhs privacy on --for 600    # …durante 10 minutos
jhs --on-screen             # volver
jhs shutdown in 90          # apagar en 90 minutos
jhs programar-apagado 23:30
jhs cancelar-apagado
jhs status --json
jhs update --check
